Étape 2 — Clonage du Projet & Configuration Sécurisée de l'Environnement

Clonez le dépôt et générez le fichier de production local .env.rpi5 avec des secrets uniques :

⚠️ Avertissement Sécurité & Rotation des Clés : Ne réutilisez jamais une clé secrète ou un mot de passe par défaut. Toute clé ou mot de passe précédemment exposé dans un exemple ou un guide doit être immédiatement révoqué et remplacé par des valeurs cryptographiquement aléatoires avant mise en service. 
cd ~
git clone https://github.com/raillersing/hahitantsoa-titan-erp.git
cd hahitantsoa-titan-erp

# 1. Génération de secrets uniques et aléatoires
SECRET_KEY=$(openssl rand -hex 32)
DB_PASSWORD=$(openssl rand -hex 24)
REDIS_PWD=$(openssl rand -hex 24)

# 2. Création du fichier d'environnement local non versionné
cat << 'ENV_EOF' > .env.rpi5
DJANGO_DEBUG=False
DJANGO_SECRET_KEY=${SECRET_KEY}

# Autorisation du réseau local et du nom mDNS
DJANGO_ALLOWED_HOSTS=127.0.0.1,localhost,hahitantsoa-erp,hahitantsoa-erp.local,192.168.1.*,192.168.88.*,*
DJANGO_CSRF_TRUSTED_ORIGINS=http://127.0.0.1,http://localhost,http://hahitantsoa-erp,http://hahitantsoa-erp.local,http://192.168.1.*,http://192.168.88.*

# Base de données PostgreSQL sur SSD NVMe
POSTGRES_DB=hahitantsoa_titan
POSTGRES_USER=hahitantsoa_titan
POSTGRES_PASSWORD=${DB_PASSWORD}

# Redis Cache
REDIS_PASSWORD=${REDIS_PWD}

# Moteur PDF
DOCUMENT_PDF_GENERATOR_CLASS=apps.documents.pdf.WeasyPrintPDFGenerator

# Port Web d'Accès
CLIENT_APP_PORT=80
ENV_EOF

# 3. Verrouillage des permissions du fichier de configuration
chmod 600 .env.rpi5

# Création du service systemd

EOF"
