Gestion des Utilisateurs, Rôles & Permissions (RBAC)

Contrôle d'accès strict selon le modèle de sécurité Ergon ERP

Rôle Applicatif Identifiant Technique (Slug) Périmètre & Droits Autorisés
Super-Administrateur is_superuser / is_staff Accès total sans restriction : configuration système, suppression protégée, audit, gestion des comptes.
Admin des Identités identity_admin Création et modification des comptes collaborateurs, attribution et révocation des rôles.
Opérateur Commercial Sensible reservation_sensitive_operator Signature des contrats, validation de l'acompte, confirmation formelle des réservations et journal d'audit.
Opérateur Logistique & Stock logistics_operator Préparation des matériels, signature du Bon de Livraison (BL), pointage des retours et déclaration des casses.
Caissier / Finance cashbox_operator Ouverture/clôture de session de caisse, encaissement des acomptes, émission des reçus thermiques 80 mm, restitution caution.

Commandes d'administration des comptes :

# 1. Créer un nouvel utilisateur
docker compose --env-file .env.rpi5 -f deploy/client/compose.yaml exec backend python backend/manage.py shell -c "
from django.contrib.auth import get_user_model
from apps.identity.models import ApplicationRole, UserRoleAssignment
User = get_user_model()

# Création du compte utilisateur
user, created = User.objects.get_or_create(username='commercial1', email='commercial@hahitantsoa.mg')
if created:
    user.set_password('MotDePasseCommercial2026!')
    user.save()
    print('Utilisateur créé avec succès !')

# Attribution du rôle Opérateur Commercial Sensible
role = ApplicationRole.objects.get(slug='reservation_sensitive_operator')
UserRoleAssignment.objects.get_or_create(user=user, role=role)
print(f'Rôle {role.name} assigné !')
"

# 2. Réinitialiser le mot de passe d'un utilisateur existant
docker compose --env-file .env.rpi5 -f deploy/client/compose.yaml exec backend python backend/manage.py changepassword commercial1

Paramétrage des Barèmes Métier Hahitantsoa 2026

Configuration des forfaits de salle, options de prolongation nocturne et cautions obligatoires

A. Location Nue (Fête de Jour)

  • Forfait de base (jusqu'à 250 pers) : 6 500 000 Ar TTC
  • Invité supplémentaire (> 250) : +5 000 Ar / pers
  • Accès préparatifs (J-1 ou Jour J) : 15h30 / 23h30 ou 07h00
  • Libération complète des lieux : 20h00

B. Options de Prolongation Nocturne

  • Option Nuit 1 (Fin 21h00 / Sortie 22h30) : +300 000 Ar
  • Option Nuit 2 (Fin 00h00 / Sortie 03h30) : +500 000 Ar
  • Sécurité de Nuit (Obligatoire dès Option 1/2) : +120 000 Ar
  • Caution de Garantie (Obligatoire) : 500 000 Ar

Configuration Financière, Banques & Caisse

Paramétrage des comptes de règlement bancaires, Mobile Money et sessions de caisse

Les coordonnées bancaires et numéros de compte Mobile Money apparaissent automatiquement en bas des Factures Proformas et des Contrats pour orienter les virements des clients. 

# Initialisation des comptes bancaires de l'agence
docker compose --env-file .env.rpi5 -f deploy/client/compose.yaml exec backend python backend/manage.py shell -c "
from apps.finance.models import BankAccount

comptes = [
    {'bank_name': 'BNI Madagascar', 'account_number': '00005 00001 12345678901 23', 'account_holder': 'HAHITANTSOA SARL', 'is_active': True},
    {'bank_name': 'BOA Madagascar', 'account_number': '00009 01000 98765432101 45', 'account_holder': 'HAHITANTSOA SARL', 'is_active': True},
    {'bank_name': 'MVola (Telma)', 'account_number': '034 00 000 00', 'account_holder': 'HAHITANTSOA SARL', 'is_active': True},
    {'bank_name': 'Orange Money', 'account_number': '032 00 000 00', 'account_holder': 'HAHITANTSOA SARL', 'is_active': True},
]

for c in comptes:
    acc, created = BankAccount.objects.get_or_create(bank_name=c['bank_name'], defaults=c)
    if not created:
        for k, v in c.items(): setattr(acc, k, v)
        acc.save()

print('Comptes bancaires et Mobile Money configurés avec succès !')
"

Catalogue Matériel & Formules de Packs

Import des articles de location Titan et création des packages commerciaux

1. Import initial du catalogue : Vous pouvez charger la liste de votre inventaire de matériel soit depuis l'écran « Import Excel » (#import-excel), soit via la commande de pré-remplissage : 

docker compose --env-file .env.rpi5 -f deploy/client/compose.yaml exec backend python backend/manage.py seed_demo_inventory

2. Création des Packs Clé en main : Rendez-vous sur l'écran « Packs » (#packages) pour composer vos lots (ex: Pack Réception Prestige 100 pax, Pack Éclairage Guinguette). Vous pouvez y glisser-déposer des photos locales, définir la tarification forfaitaire et visualiser l'avantage client calculé automatiquement.

Tuning Haute Performance PostgreSQL 17 (RPi 5 16 Go + NVMe)

Optimisation des paramètres mémoire PostgreSQL pour exploiter les 16 Go de RAM

Grâce aux 16 Go de RAM et au SSD NVMe, vous pouvez attribuer une mémoire cache généreuse à PostgreSQL pour rendre toutes les requêtes (planning, rapports, vérification des stocks) instantanées : 

# Paramètres recommandés pour PostgreSQL 17 sur Raspberry Pi 5 16Go
shared_buffers = 3GB                  # Cache principal en RAM
work_mem = 64MB                       # Mémoire allouée par opération de tri
maintenance_work_mem = 512MB          # Mémoire pour les index et vacuum
effective_cache_size = 10GB           # Estimation de la mémoire disponible
random_page_cost = 1.1                # Optimisé pour SSD NVMe ultra-rapide
effective_io_concurrency = 200        # Entrées/Sorties parallèles sur SSD
max_worker_processes = 4              # 4 Cœurs CPU Broadcom
max_parallel_workers = 4
